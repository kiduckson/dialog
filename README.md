# WindowDialog

The `WindowDialog` component provides a draggable, resizable, and dynamic dialog system with support for tabbed interfaces. Built using React, Framer Motion, and Zustand for state management, this component allows seamless manipulation of dialogs with advanced features like merging, splitting, and resizing.

## Features

- **Draggable and Resizable Dialogs**: Move and resize dialogs within the container.
- **Tabbed Interface**: Support for multiple tabs within dialogs, with the ability to reorder, merge, or split tabs.
- **Dynamic Behavior**: Handles complex interactions such as tab merging, splitting into new dialogs, and position adjustments.
- **Customizable**: State management is externalized using Zustand, making the system adaptable to various requirements.
- **Smooth Animations**: Built-in support for Framer Motion ensures fluid transitions and interactions.

## Installation

1. Clone the repository or copy the component.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Add the component to your project.
